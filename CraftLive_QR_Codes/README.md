# Craft-live 素材登録QRコード

Pad3の「QR 読み取り開始」から読み取ってください。QRコードには、ゲームの`CraftLiveQrScanner`が正式対応している `craftlive:material:<素材ID>` 形式を格納しています。

| ファイル | 素材 | 素材ID | QR内容 |
|---|---|---|---|
| `01_fire_crystal.png` | 炎の結晶 | `attribute_fire` | `craftlive:material:attribute_fire` |
| `02_ice.png` | 氷 | `attribute_freeze` | `craftlive:material:attribute_freeze` |
| `03_lightning.png` | 雷 | `attribute_lighting` | `craftlive:material:attribute_lighting` |
| `04_double_strike.png` | 二回攻撃 | `skill_double_strike` | `craftlive:material:skill_double_strike` |
| `05_auto_heal.png` | 自動回復 | `skill_auto_heal` | `craftlive:material:skill_auto_heal` |
| `06_life_orb.png` | 命の珠 | `skill_life_orb` | `craftlive:material:skill_life_orb` |
| `07_luck.png` | 幸運 | `skill_luck` | `craftlive:material:skill_luck` |

印刷時は画像を変形・トリミングせず、四辺の白い余白を残してください。QRコードは誤り訂正レベルQで生成しています。
