## 実行構成

1つのWebGLビルドに次の5シーンを含める。

1. `CraftLiveBootstrap.unity`
2. `Pad1_MaterialGallery.unity`
3. `Pad2_Workbench.unity`
4. `Pad3_StatusQr.unity`
5. `Pad4_Hologram.unity`

BootstrapをBuild Index 0とする。各iPadは同じURLへ接続し、
`screen`で担当Pad、`room`で共有セッションを指定する。

```text
?screen=pad1&room=001
?screen=pad2&room=001
?screen=pad3&room=001
?screen=pad4&room=001
```

シーンはPadごとに分けるが、ビルドは分けない。Bootstrapが選択したPadシーンを
Additiveロードする。旧`Assets/Scenes/Craft.unity`は削除せず互換用に残し、
Step2以降のBuild Settingsでは無効にする。

## 共通仕様

- 対象: Unity 6000.4.0f1、URP、WebGL
- 共有状態形式: RoomState V5
- 端末: iPad第9世代、縦画面、3:4
- UI、台、ボタン、完成済み3DモデルはユーザーがInspectorで接続する
- 3Dモデル制作、細かなアニメーション制作は実装対象外
- 未接続の見た目は空の接続先または仮アセットで代用する
- 初見の来場者が迷わないことを優先し、現在操作可能な対象だけを強調する
- 一連の演出は数秒程度で進行させる
- セッション制限時間内は武器を複数作成できる
- 終了後に完成武器を1つ選び、武器コードを発行する

## Pad1 素材ギャラリー・転送

- 素材の描かれた絵画がある壁を縦方向にスクロールして選ぶ
- 壁は横に3列並ぶ
  - パワーアップ: 基礎ステータス素材
  - スキル: 固有スキル素材
  - タイプ: 属性素材
- 絵画をタップすると素材の3Dモデルが手前へ飛び出す
- 近くの小型ホログラム板に説明、属性、能力、用途などを表示する
- Pad2で配置先を確定すると、素材モデルは絵画へ戻る
- 額縁ごとPad1下部の転送待機エリアへ移動する
- 転送待ちは1個でも複数でもまとめて発射できる
- 配置確定時は即発射せず、Pad1の転送待ちリストへ追加する
- 同じ配置枠は、配置済みまたは転送予約済みなら選択できない
- プレイヤーがばねを引き、離すと額縁がレールに沿って斜方投射される
- レール確認時はカメラを少し移動し、発射後に戻す

## Pad2 武器選択・素材配置・合成

- 合成前に剣、突き、杖の3タイプに属する武器候補から選ぶ
- 武器モデルをホログラム風に浮かせ、横スライドで選択する
- 中央に武器、周囲に6つの素材枠を配置する
- 参考画像に対応する枠制約
  - 左上、左中、右上、右中: 基礎ステータス素材
  - 左下: 固有スキル素材
  - 右下: 属性素材
- Pad1で選択中の素材を置ける枠だけを発光させる
- 枠タップ後は仮配置し、最終確認までは変更・キャンセル可能にする
- 確定後、Pad1の転送待機へ追加する
- 転送後、該当素材の3Dモデルが上から降り、選択枠にはまる
- 配置された素材が変わるたびにステータスを即再計算する
- 素材テーマカラーの液体が中央へ流れ、流れ切ると停止する
- 合成ボタンでトンカチとガイドレールを表示する
- ガイドに沿って数往復スライドし、武器を叩いて合成する
- 成功後は詳細ステータスをホログラム板に表示する
- 必要往復数と1ストローク距離は`CraftLiveRules`で変更可能
- 完成後、残り時間があれば作業台を空にして次の武器を作れる

## Pad3 QR登録・ステータス管

- 上側: 攻撃力、防御力、回避率の3本のガラス管
- 下側: QR読み取り開始ボタン
- 素材QRを一度登録すると、そのセッション中は何度でも使える
- 同じQRの再読み取りで個数や使用回数は増えない
- 配置素材が1つ変わるたびに3本の管を更新する
- Pad2の液体演出が完了したタイミングで新しい値へ動かす
- 現在は液体実装前のため、Pad2到着完了後の短い待機で公開値を更新する

## Pad4 完成武器ホログラム

- 完成武器モデルを回転表示する
- iPad第9世代の縦画面で、画面端に触れない最大サイズへ調整する
- 現実のプラ板を使うホログラム表示を想定する
- プラ板寸法、角度、iPadからの距離、モデル位置、回転、拡大率を
  `CraftLivePad4Calibration`からInspectorで変更可能にする
- 最終選択後は武器名と発行コードも表示する

## 素材とステータス

- 基礎ステータス素材
  - 攻撃力、防御力、回避率の補正値を持つ
  - 4つの基礎枠をすべて必須にするかは`CraftLiveRules`で変更可能
- 属性素材
  - 炎、凍結、雷
  - 発動確率、効果量、持続時間をInspectorで変更可能
- 固有スキル素材
  - 幸運、2連撃、自動回復、命の珠
  - 発動確率、主効果値、副効果値、発動間隔をInspectorで変更可能
- 武器
  - 武器名、武器タイプ、基礎3ステータス、各表示PrefabをInspectorで変更可能
- 表示・計算する基礎ステータスは攻撃力、防御力、回避率のみ
- 旧`ElementBoost`は保存互換のためフィールドだけ残し、V3では計算・表示しない

## Inspectorで変更できる主要値

- 素材名、説明、カテゴリ、フォーム、絵、テーマカラー、各Prefab
- 基礎素材の攻撃力、防御力、回避率補正
- 属性の種類、発動確率、効果量、持続時間
- 固有スキルの種類、発動確率、主効果値、副効果値、発動間隔
- 武器名、武器タイプ、基礎ステータス、各表示Prefab
- セッション制限時間
- 基礎4枠を必須にするか
- 合成時間、成功条件、ランクボーナス、ステータス上限
- トンカチ必要往復数、ストローク距離、履歴上限、コード接頭辞
- Firebase URL、Editor/WebGLで通信を使うか、通信間隔、タイムアウト
- 各Padのカメラ位置、投影方式、画角、背景色
- Pad4のプラ板・モデル表示補正

## 安全規則

- 各ステップでコンパイル、プロジェクト検証、EditModeテストを行う
- 既存のID、enum数値、公開メソッドを途中で変更しない
- 保存形式を変える場合は旧形式からの移行テストを追加する
- 既存シーンやPrefabを一括削除・上書きしない
- 新しいシーン生成器は既存シーンを上書きしない
- 参照が未設定の場合は検証エラーで止め、実行時はnull参照で崩さない
- 見た目のPrefab接続はコアロジックと分離する
