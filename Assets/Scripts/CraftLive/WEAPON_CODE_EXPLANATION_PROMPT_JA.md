# 武器コード説明用プロンプト

以下をそのままAIや担当者への説明依頼に使用できます。

```text
CraftOriginの武器コード仕様を、イベント当日の運営スタッフにも分かる日本語で説明してください。

武器コードはインターネットやデータベースを使わず、コードだけで完成内容を判別するための6文字コードです。

形式：
[武器][属性][スキル][攻撃素材数][防御素材数][回避素材数]

1文字目（武器）：
2 = 大剣
3 = ふで
4 = 片手剣
5 = カジキマグロ（隠し武器）
6 = 素手（隠し武器）
7 = ピコピコハンマー（隠し武器）
8 = 杖
9 = やり

2文字目（属性）：
N = なし
F = 炎
C = 氷（Cold）
T = 雷（Thunder）

3文字目（スキル）：
N = なし
L = 幸運
D = 二回攻撃
H = 自動回復
B = 命の珠

4〜6文字目（強化素材数）：
4文字目 = 攻撃素材の個数
5文字目 = 防御素材の個数
6文字目 = 回避素材の個数
各値は0〜4で、合計は最大4です。

隠し武器はステータスが武器固有値へ固定されます。強化素材や合成ランクによる補正は受けず、コードの4〜6文字目は必ず000になります。

コードにはルーム番号、完成日時、結果番号、接頭辞、ハッシュ値を含めません。同じ武器・属性・スキル・素材個数なら、必ず同じコードになります。

説明では、例「2FD211」を使って各文字を順番に分解してください。この例は「大剣、炎属性、二回攻撃、攻撃素材2個、防御素材1個、回避素材1個」を意味します。

最後に、スタッフが当日確認する手順を3段階以内で簡潔にまとめてください。
```
