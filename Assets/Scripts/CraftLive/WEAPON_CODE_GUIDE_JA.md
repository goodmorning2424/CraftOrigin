# 武器コード 当日判別表

武器コードは6文字で、形式は次のとおりです。

```text
[武器][属性][スキル][攻撃素材数][防御素材数][回避素材数]
```

ルーム番号、完成日時、結果番号、ハッシュ値は含みません。

例：`2FD211`

- `2`：大剣
- `F`：炎
- `D`：二回攻撃
- `2`：攻撃素材2個
- `1`：防御素材1個
- `1`：回避素材1個

## 1文字目：武器

| 記号 | 武器 |
|---:|---|
| `2` | 大剣 |
| `3` | ふで |
| `4` | 片手剣 |
| `5` | カジキマグロ（隠し武器） |
| `6` | 素手（隠し武器） |
| `7` | ピコピコハンマー（隠し武器） |
| `8` | 杖 |
| `9` | やり |

## 2文字目：属性

| 記号 | 属性 |
|---:|---|
| `N` | なし |
| `F` | 炎 |
| `C` | 氷（Cold） |
| `T` | 雷（Thunder） |

## 3文字目：スキル

| 記号 |スキル |
|---:|---|
| `N` | なし |
| `L` | 幸運 |
| `D` | 二回攻撃 |
| `H` | 自動回復 |
| `B` | 命の珠 |

## 4〜6文字目：強化素材数

| 位置 | 内容 | 値 |
|---:|---|---|
| 4文字目 | 攻撃素材の個数 | `0`〜`4` |
| 5文字目 | 防御素材の個数 | `0`〜`4` |
| 6文字目 | 回避素材の個数 | `0`〜`4` |

3種類の合計は、基礎素材スロット数である4以下になります。

隠し武器のステータスは固定です。そのため、カジキマグロ、素手、
ピコピコハンマーの4〜6文字目は必ず`000`になります。
